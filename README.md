# Placement Skill Compass

Build a sleek, modern, responsive web application called "SkillPulse - Placement Readiness & Skill-Gap Analyzer" designed for college students preparing for campus placements. Include: 1. A clean hero header with the app title and a brief subtitle. 2. A selector for Target Job Role (Software Developer, Data Analyst, Business Analyst, QA Automation Engineer) and a toggle for Company Track (Service-Based vs Product-Based). 3. An interactive checklist of 10-12 relevant skills per role grouped into Technical Skills, Tools, and Soft Skills. 4. A real-time circular Readiness Score gauge (0% to 100%) that updates immediately as checkboxes are selected, showing a status badge (Needs Prep, Getting Close, Placement Ready). 5. A dynamic "Missing Skills & Action Roadmap" panel that automatically displays unchecked skills with a 1-week action tip for each. 6. A "Copy / Print Readiness Summary" button and a "Reset Checklist" button. Use a professional navy blue and white color palette with clean cards and mobile responsiveness.
